# Evidence categories
1. HISTORICAL_REPORTED: metrics quoted from preserved reports, not newly reproduced.
2. ARTIFACT_INSPECTED: existing source/data/report read directly.
3. ARTIFACT_RECOMPUTED: numerical metadata or integrity result calculated from available artifacts.
4. CURRENT_CODE_TESTED: current implementation executed against documented fixtures.
5. SOURCE_REPRODUCED: downstream data verified against available raw source; limited to that derivation.
6. HYPOTHESIS: testable explanation, not a finding.
7. UNRESOLVED: missing evidence or scientific choice.
These are categories, not interchangeable numerical grades. A synthetic test is not a benchmark. Prepared RGB/RLE equivalence to Parquet is not verification of upstream polygon drawing or biological identities.
