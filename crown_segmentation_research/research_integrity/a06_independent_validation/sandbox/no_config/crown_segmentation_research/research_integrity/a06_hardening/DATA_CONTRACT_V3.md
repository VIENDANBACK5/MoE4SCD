# TreeFlowNet Data Contract V3

**Version:** 3.0.0  
**Status:** Frozen Data Specification  
**Effective Date:** 2026-10-15  
**Governing Principle:** No silent data modification. No unversioned transforms. No conflation of derived rasters with original annotations.

---

## 1. Imagery Specifications

1. **Format & Precision**:
   - Tiles are stored as NumPy compressed archives (`.npz`) containing:
     - `image`: uint8 RGB array of shape `(H, W, 3)`.
     - `valid`: boolean or uint8 mask of shape `(H, W)`, where `True` (1) denotes usable imagery within the survey AOI and `False` (0) denotes nodata/black border padding.
     - `label`: int32 array of shape `(H, W)`, representing rasterized priority ownership (derived diagnostic raster only; NOT primary GT).
2. **Coordinate Reference System (CRS) & Transform**:
   - Primary CRS: `EPSG:32618` (UTM Zone 18N).
   - Pixel dimensions: Approximately $a_x = 0.03\text{ m}, a_y = -0.03\text{ m}$ per axis.
   - Deterministic Ground Area: Pixel area is computed from the georeferenced affine transformation matrix $A$:
     $$\Delta A_{px} = |\det(A)| = |a_x a_y - a_{xy} a_{yx}|$$
     For axis-aligned tiles: $\Delta A_{px} = |a_x \cdot a_y| \approx 0.0009\text{ m}^2$.

---

## 2. Annotation Specifications (COCO / RLE)

1. **Format**:
   - Stored in standard COCO format (`instances_{split}.json`) with segmentation encoded as uncompressed or compressed Run-Length Encoding (RLE):
     ```json
     {
       "size": [H, W],
       "counts": "..."
     }
     ```
2. **Integrity Invariants**:
   - **Non-Zero Area**: Every annotation record $i$ must satisfy $N_i^{RLE} > 0$. Zero-area records are strictly forbidden and rejected at preflight.
   - **Boundary Bounds**: All RLE runs must strictly satisfy $0 \le \text{starts} < \text{ends} \le H \times W$.
   - **Identifier Scope**: Annotation IDs restart within each split; therefore, unique global keys MUST be formatted as `{split}:{annotation_id}`.
   - **Category**: Single-class foreground: `category_id = 1` ("tree_crown").

---

## 3. Support & Ownership Definitions

Original annotations allow physical polygon overlap (representing overlapping tree branches or canopy strata). The contract distinguishes six distinct geometric support sets:
1. **Original Support ($M_i$)**: The full binary mask decoded from the raw COCO RLE.
2. **Valid Support ($S_i^{valid}$)**: $M_i \cap V$, where $V$ is the binary valid mask.
3. **Unique Original Support ($U_i$)**: $M_i \setminus \bigcup_{j \ne i} M_j$.
4. **Unique Valid Support ($U_i^{valid}$)**: $U_i \cap V$.
5. **Priority Ownership ($S_i^{priority}$)**: Mutually disjoint raster assignment generated by deterministic conflict resolution.
6. **Priority Ownership Valid ($S_i^{priority\_valid}$)**: $S_i^{priority} \cap V$.

---

## 4. Area Conventions

To resolve discrepancies between floating-point vector area and discrete raster area:
- **Primary Canonical Metric Area**:
  $$A_i^{m^2} = N_i^{RLE} \cdot \Delta A_{px}$$
- **Size-Bin Stratification**:
  - `lt1`: $A_i^{m^2} < 1.0\text{ m}^2$
  - `1to2`: $1.0\text{ m}^2 \le A_i^{m^2} < 2.0\text{ m}^2$
  - `2to4`: $2.0\text{ m}^2 \le A_i^{m^2} < 4.0\text{ m}^2$
  - `4to9`: $4.0\text{ m}^2 \le A_i^{m^2} < 9.0\text{ m}^2$
  - `ge9`: $A_i^{m^2} \ge 9.0\text{ m}^2$
- **Metadata Preservation**: Native COCO `area` fields are preserved unchanged in the dataset JSON for historical traceability.
