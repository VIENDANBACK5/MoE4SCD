The primary interchange metrics and operational pattern are already known. This supplementary saved-mask analysis is therefore exploratory and cannot change the registered screen.

Compare that exact source query with itself in its factual pool: ABqueryq versus AAqueryq, BAqueryq versus BBqueryq. It is a diagnostic localization descriptor, never an inference selector.
