# Mask DINO

Feng Li et al., CVPR2023. [Accepted paper](https://openaccess.thecvf.com/content/CVPR2023/html/Li_Mask_DINO_Towards_a_Unified_Transformer-Based_Framework_for_Object_Detection_CVPR_2023_paper.html), [official implementation](https://github.com/IDEA-Research/MaskDINO).

The mask branch combines query-derived embeddings with a dense pixel embedding field through a dot product. The local archived source was inspected through final decoder predictions and forward_prediction_heads. This actual factorization permits the finite interchange diagnostic; it does not make the diagnostic a new segmentation method. Query selection, box initialization, decoder processing and class prediction remain upstream of the captured final embeddings.

This project uses its completed mask-only adapted carrier, not a new faithful full-paper reproduction. The source/config/checkpoint bindings determine the actual model. No MaskDINO mechanism is claimed novel.
